# 理監事資訊公開網站 (Board Info Site)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

> 協助金融機構揭露治理資訊

## 📖 背景

信用合作社與農漁會依法需定期公開理監事名冊與會議資訊，但過去多仰賴散落的試算表
與紙本文件，查閱不便且難以即時更新。本工具提供單頁式介面，將聯絡資訊、會議通知、
職務分配集中管理，讓管理階層與理監事隨時用手機查閱最新資料。

## 🎯 給誰用

- 信用合作社 / 農漁會理監事
- 治理資訊公開需求
- 管理階層聯絡與會議通知管理

## ✨ 功能

- 🏢 理監事聯絡資訊管理介面
- 📅 會議通知與職務分配查詢
- 🌐 手機隨時查閱通訊錄與最新公告
- 🔒 集中管理通訊錄，避免敏感資訊外流

## 🧰 技術棧

- HTML / CSS
- GitHub Pages 部署
